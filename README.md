# Programacion-Python-Bayes
Taller de Programacion en Python con Perfil Bayesiano

Temario Detallado de Python:

    INTRODUCCION y FUNDAMENTOS
        ¿Qué es Python? Características y filosofía.
        Instalación y configuración del entorno (IDEs, intérprete).
        Sintaxis básica y comentarios.
        Variables, palabras clave y tipos de datos (enteros, flotantes, cadenas, booleanos).
        Operadores aritméticos, lógicos y relacionales.
        Entrada y salida de datos (input/print).

    ESTRUCTURAS de CONTROL
        CONDICIONALES: if, elif, else.
        BUCLES ITERATIVOS: for, while.
        SENTENCIAS de CONTROL: break, continue, pass.

    ESTRUCTURAS de DATOS
        LISTAS: métodos, índices, sublistas.
        TUPLAS: creación y desempaquetado.
        DICCIONARIOS de DATOS: llaves y valores.
        CONJUNTOS (Sets).
        CADENAS de TEXTO (Strings): manipulación y formateo (f-strings).

    FUNCIONES
        DEFINICION y LLAMADA de FUNCIONES.
        PARAMETROS y ARGUMENTOS.
        RETORNO de PROCESO o datos de RESPUESTA (RETURN).
        VARIABLES GLOBALEAS y LOCALES.
        Funciones lambda (programación funcional).
  MODULARIZACION

    Programación Orientada a Objetos (POO)
        Creación de clases y objetos.
        Atributos y métodos (init, self).
        Herencia y polimorfismo.

    Manejo de Errores, Ficheros y Módulos
        Gestión de excepciones (try, except, finally).
        Lectura y escritura de ficheros.
        Importación de módulos y librerías (import).
        Uso de la librería estándar (fechas, sistema operativo, matemáticas).

    INTRODUCCION a CIENCIAS de DATOS
        Cálculos matemáticos con NUMPY.
        Análisis exploratorio de datos, limpieza, validación.
        Manipulación de datos con PANDAS. Guardar en formato Texto Plano y Planilla de Cálculo tipo Excel.
        Visualización de datos con MATPLOTLIB, SEABORN, PLOTLY, ALTAIR. 

Este temario es común en cursos introductorios y profesionales, siendo la documentación oficial de Python el recurso definitivo para su estudio.
